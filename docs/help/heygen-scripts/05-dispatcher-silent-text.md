# 05 — Silent Text Link

| Field | Value |
|---|---|
| Video ID | `psap-silent-text` |
| Audience | Dispatcher, Supervisor |
| Target length | 4:00 |
| Tone | Safety-first, domestic-violence aware |

## On-screen cues

1. Right panel: **SILENT TEXT LINK**
2. E.164 number confirm
3. Send → SMS to caller
4. Text thread in workspace
5. Audit trail note
6. Fallback: Caller Video Assist (only if safe)

## Narration (HeyGen)

Use Silent Text when a caller cannot speak safely and needs to communicate by text only.

Typical situations: domestic violence where speaking could escalate danger; a caller who is hiding and cannot make noise; or any call where the caller signals they cannot talk.

Open the incident. In the right panel, find Silent Text Link. Confirm the caller’s mobile number in E-dot-one-six-four format — for example, plus one, then the ten-digit mobile. Do not send to a landline.

Click Send Silent Text Link. The caller receives a plain S-M-S with a one-time secure link. No app download. When they open it, a text thread appears in your workspace. Reply there. Every message is logged to the incident audit trail automatically.

If the S-M-S does not deliver, confirm it is a mobile number, resend once if policy allows, and consider safer alternatives. Do not push Caller Video Assist if holding up a phone would endanger them.

Close the session when the caller navigates away, times out, or you end it manually. Silent Text is assistive. Your SOP and scene safety still lead.
