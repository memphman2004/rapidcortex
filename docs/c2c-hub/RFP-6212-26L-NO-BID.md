# RFP 6212-27L — no-bid as prime

**Solicitation:** Charleston County, SC — CAD-to-CAD System for the Consolidated 9-1-1 Dispatch Center.  
**Public number:** **RFP No. 6212-27L** (due 2026-10-06 12:00). Related CAD RFI was **6201-26L**; older C2C RFI **5849-24L**. Internal shorthand **6212-26L** refers to this C2C buy, not a separate bid.

## Decision

Rapid Cortex **will not bid as prime**.

The hub in this repo is for:

- Vendor leverage (Southern Software + CentralSquare partner API conversations)
- A working EIDO demo (Berkeley County → Charleston County)
- Future pipeline if a prime or the county wants a NENA-neutral translation layer

It is **not** an RFP response, cost proposal, or functional-requirements matrix for 6212-27L.

## Why

Charleston County asked for a **turnkey CAD-to-CAD** system with expansion to regional partners. Rapid Cortex is an intelligence / interoperability layer, not a replacement for a prime C2C integrator with existing CAD certifications and on-site implementation crews. Bidding as prime would over-claim.

## Allowed follow-up

- Partner API inquiries (see `emails/`).
- Subcontract / translation-layer conversations **if a prime invites us** after award discussions.
- Keep the mock hub current so we can demo EIDO transfer in a meeting.

Do not submit a proposal packet to Charleston County procurement for 6212-27L from this workstream.
