# SOP — Risk assessment refresh

**TSC:** CC3.2–CC3.4  
**Policy:** [POL-06](../policies/06-risk-assessment-policy.md)  
**Cadence:** Quarterly

1. Review [risk-register.md](../evidence/risk-register.md) and [phase-0/risk-register.md](../../../phase-0/risk-register.md).
2. Close items that have evidence; add new ones from incidents, vendor changes, or deploy blockers ([NEXT_DEPLOY_BLOCKERS.md](../../../deployment-infrastructure/NEXT_DEPLOY_BLOCKERS.md) PLT-002/025/026).
3. Confirm R-SOC-001 (shared account) still accepted or migration started.
4. Confirm R-SOC-002 (SAM CloudTrail must stay off on live) still understood.
5. Date the quarterly review in the register.
