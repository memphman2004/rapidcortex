# Venue Security

You log section incidents and act on guest reports. You are not a 911 dispatcher.

## You can

- Create section incidents
- Work Guest Reports intake
- Use cameras and zones for awareness

## You cannot

- Use this console as CAD
- Assume you can deactivate QR — that is Admin / Supervisor / Operator unless your account was granted manage

## Typical event

Walk your section, watch inbound guest reports, and call 911 for in-progress emergencies. If a posted code is wrong, tell Supervisor rather than leaving guests on a dead scan.
