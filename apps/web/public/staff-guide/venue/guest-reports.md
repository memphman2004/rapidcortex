# Guest Reports inbox (Venue)

Guest Reports is how visitors tell venue staff about issues. **Guest Services** users live in this inbox. It is **not** a 911 dispatch queue and it is **not** the security incident table.

## Where reports come from

- Posted **QR** scans
- **NFC** taps
- A dedicated venue **SMS** number, when the venue has provisioned one
- Staff entry

The location on the report is the section named on the code that was scanned. A wrong code sends the guest’s words to the wrong section.

## Work the inbox

1. Open **Guest Reports**. For Guest Services, this inbox is the home screen.
2. Read the section or gate before you answer.
3. Lost property, directions, accessibility, and other non-emergency guest issues: handle them per venue SOP. Add a note when you hand the guest off.
4. If the report describes violence, fire, a medical emergency, or anything your event plan sends to public safety, **call 911** or radio Supervisor / Security immediately. Do not wait for a software route.
5. When several guests report the same section, note that they are the same event so Security is not sent three times.

## What each role sees

- **Guest Services** — this inbox only. No cameras, no QR management, no incident command. The 911 disclaimer stays on the page.
- **Security and Supervisor** — the inbox plus section incidents, so a guest report can become a section response.
- **Operator** — does not run this inbox as a dispatch floor. Operators keep the posted codes accurate.

## Wrong section

If guests are landing on the wrong gate, tell Venue Admin or Operator. They deactivate the bad code and post a corrected one. Do not leave a wrong sign up because the inbox is busy.
