# Guest Reports inbox (Venue)

Guest Reports is how visitors tell venue staff about issues. **Guest Services** users live in this inbox. It is **not** a 911 dispatch queue.

## Where reports come from

- Posted **QR** scans
- **NFC** taps
- Dedicated venue **SMS** number (when provisioned)
- Staff entry

## Work the inbox

1. Open **Guest Reports** (Guest Services home is this inbox).
2. Read the location (section / gate) from the code that was scanned.
3. For lost property, directions, and non-emergency guest issues, handle per venue SOP.
4. If the report is an in-progress emergency, **call 911** or radio Supervisor / Security immediately.
5. Duplicate reports about the same section can be linked in notes so Security is not triple-dispatched.

## What you will not see

Guest Services does not get cameras, QR management, or incident command. That is intentional.

If a code posts to the wrong section, tell Venue Admin or Operator so they can deactivate and reprint.
