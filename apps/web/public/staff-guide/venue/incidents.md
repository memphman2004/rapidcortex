# Work venue incidents

**Incidents** are venue-scoped: a section, gate, club, or concourse. There is no PSAP incident table and no CAD entry on this console.

## Who works the queue

- **Venue Admin, Supervisor, and Security** open, update, and close section incidents.
- **Venue Operator** can view incidents. Creating and closing them is not the operator job.
- **Guest Services** does not see this queue. They work **Guest Reports** only.

## Open the queue

1. Sign in to the venue console.
2. Select **Incidents**.
3. Confirm orange venue branding. A sky-blue 911 workspace means you are in the wrong product.

## Handle an incident

1. Open the row and confirm the section or zone. If the location does not match the report, fix the note and tell whoever owns the QR post.
2. Add notes a later shift can use: what you saw, who you told, and what is still open. Write facts, not guesses.
3. When a guest report is the same event, say so in the notes so Security is not sent twice.
4. Use cameras if your role has them. Camera AI is a tip, not a dispatch order.
5. Close the incident when the venue response is done per SOP.

## Create one

Security and Supervisor start a section incident from **Incidents** when staff observe something that did not arrive as a guest report. Set the section. Do not invent a CAD event number. There is no CAD number on this console.

## Emergencies

Call 911 first, then keep the venue incident current. An in-product escalation is a handoff note for venue staff. It is not CAD write-back and it does not place the call.

## After the event

Deactivate temporary QR posts so leftover signs do not create overnight reports. See **Delete locations from the dashboard**.
