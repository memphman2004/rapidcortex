# Zones and sections (Venue)

**Zones** are gates, levels, clubs, and sections. Incidents, guest reports, and QR posts should use the same names guests see on wayfinding.

## Keep names aligned

1. Open **Zones**.
2. Match the names on printed maps and LED signage.
3. After a bowl reconfiguration, update zones, then reprint QR and reprogram NFC.

If a leftover code still says “Section 112” after that section was reseated, **Deactivate** it. See **Delete locations from the dashboard**.
