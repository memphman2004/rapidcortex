# Campus Safety overview

NexCort iQ Campus Safety is **campus public-safety intelligence**. It helps campus safety, dispatch, counseling, and administrators see incidents, buildings, QR locations, and cameras for the campuses in this tenant.

This Staff Guide is for campus employees. It is **not** the 911 Help tab used on a PSAP dispatch console.

## This product is not

- A 911 / PSAP CAD console
- A replacement for campus police radio, telephony, or medical direction
- An automatic door-lockdown system
- A Clery Act filing system or a Timely Warning publisher. Clery tools can hold a review queue. They do not file for you.

When a true emergency is in progress, **call 911**. NexCort iQ can hold the campus report and, where policy allows, record an escalation. It does not replace the PSAP.

## How the vertical is organized

One tenant can hold every campus. Operators use **All campuses** by default and can filter to one site.

- **Campus Admin** — users, settings, QR/NFC, buildings, Clery configuration. Not live 911 dispatch.
- **Campus Supervisor** — incident oversight, QR/NFC, cameras, occupant alerts. Not a PSAP floor.
- **Campus Security** — field incidents, QR report intake, cameras. View and download QR only.
- **Campus Dispatch** — campus incident queue and cameras. Not 911 CAD entry and not QR management.
- **Campus Counselor** — wellness queue only. No cameras, no command, no security incident table.
- **Campus Faculty** — submit and track safety reports. No security console.

Open **Positions** in this guide for each job. Every staff member can read every position article. Access is unlimited.

## Daily tools

- **Dashboard** — campus posture and open incidents, not a CAD workspace
- **Incidents** — campus safety reports. Counselors see the wellness queue instead of the security table
- **QR Codes** — named report codes and Location QR (RCLI)
- **Cameras / Camera AI / Video Wall** — awareness only. AI never creates an incident or dispatches units
- **Zones / Buildings** — the geography used on reports and cameras
- **Staff Guide** — this knowledge base

## How a report starts

A student or visitor scans a posted code or taps NFC. The report is tied to that building or zone. Faculty can also submit from **Reports**. If the place name is wrong, Campus Admin or Supervisor deactivates the old code and posts a corrected one. Security and Dispatch cannot do that themselves.
