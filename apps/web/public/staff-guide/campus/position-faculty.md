# Campus Faculty

Faculty accounts submit and track **safety reports**. This is not campus security command and not 911 Help.

## You can

- Open the campus dashboard and **Reports**
- Submit a safety report and check status
- Use RC Translate in view-only mode when that feature is on

## You cannot

- Manage QR/NFC, cameras, or users
- Work the security incident queue as Campus Security
- Dispatch or enter CAD

## How to report

1. Sign in to the campus console.
2. Open **Reports** and complete the faculty safety form (or follow the QR post in the building if that is the posted method).
3. For an in-progress emergency, **call 911** (or campus PD) first. The software report is documentation, not the emergency call.

If you posted or noticed a damaged QR/NFC sign, tell Campus Admin or Supervisor. They update or deactivate it from the dashboard.
