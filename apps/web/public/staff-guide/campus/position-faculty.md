# Campus Faculty

Faculty accounts submit and track **safety reports**. This is not campus security command and not 911 Help.

## You can

- Open the campus dashboard and **Reports**
- Submit a safety report and check its status
- Use Translate in view-only mode when that feature is on

## You cannot

- Manage QR, NFC, cameras, users, or buildings
- Work the security incident queue
- Dispatch units or enter CAD
- See the wellness queue used by counselors

## How to report

1. Sign in to the campus console your admin sent.
2. Open **Reports** and complete the faculty safety report, or use the QR post in the building if that is the posted method for that hall.
3. For an in-progress emergency, **call 911** or campus PD first. The software report documents what happened. It does not make the emergency call.
4. Check status later from the same Reports page. You will not see security’s camera wall while you wait.

## Damaged signs

If a QR or NFC sign in your building is missing, damaged, or names the wrong hall, tell Campus Admin or Supervisor. They update or deactivate it. You cannot turn the code off from a faculty account.

Read **When to call 911** so a classroom emergency is a phone call, not only a form.
