# Campus Dispatch

Campus Dispatch works the **campus incident queue**, cameras, and zones. This is not a 911 CAD position and not Silent Text / SOP protocol from the PSAP Help tab.

## You can

- Work the campus incident queue
- Use cameras, Camera AI, and video wall for awareness (AI never dispatches units)
- Use RC Translate when enabled
- File view-only reports where your nav allows

## You cannot

- Submit incidents to 911 CAD from this console
- Manage QR/NFC (no QR Codes item on this role)
- See counselor-only wellness workflows as a dispatch queue

## Typical shift

1. Open **Incident Queue** and work new campus reports in arrival order per SOP.
2. Attach location, camera context, and notes.
3. If the event is a public-safety emergency, call 911 (or follow campus–PSAP SOP) while keeping the campus record current.
4. Do not treat Camera AI alerts as automatic incidents.

## Coordination

Admin and Supervisor own buildings and QR posts. If callers mention a code that no longer works, route that to Supervisor — they deactivate and reprint from **QR Codes**.
