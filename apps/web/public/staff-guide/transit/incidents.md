# Work transit incidents

**Incidents** are on-system events (vehicle, station, route). They are not 911 CAD events.

## Open the list

1. Select **Incidents**.
2. Filter by vehicle, station, or route when those fields are filled.

## Create or update (Security, Supervisor, Operator)

1. Start an incident with the best location you have (vehicle ID, station, route).
2. Add notes as facts.
3. Operators report from **My vehicle** when that is the assigned unit.

## 911 escalate

Supervisor (and policy-approved roles) can flag escalation to 911. That is **audit only**. It does not write back to CAD. **You still call 911** for an in-progress emergency.

## Cameras

Open cameras on the involved vehicle or station for awareness. Camera AI does not dispatch.
