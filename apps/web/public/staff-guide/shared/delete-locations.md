# Delete locations from the dashboard

Campus, venue, and transit locations are **deactivated**, not hard-deleted. That stops scans and NFC taps immediately and keeps the record for audit.

This is not 911 Help. PSAP agency admin does not delete campus or venue locations.

Training access is **unlimited**. There is no quota on opening this article.

## Named report codes (QR & NFC)

1. Open **QR Codes** in your campus, venue, or transit console.
2. Find the reporting point.
3. Select **Deactivate**.
4. Confirm: **Deactivate this code? Scans and NFC taps will stop working.**

The row stays in the list as inactive. Filter to inactive codes if you need to confirm it is off.

To bring a location back, use the **Active** control on that row (manage permission required).

## Location QR (RCLI) / zone locations

1. Campus: **QR Codes → Location QR (RCLI)**.
2. Venue: **QR Codes** (zone location list).
3. Find the location by zone, building, or RCLI.
4. Select **Deactivate**.

Scans of that RCLI stop. Print-ready PNG/PDF links remain for records but should not be posted.

## What “delete” does not do

- It does not erase audit history, scan counts, or prior guest/student/rider reports.
- It does not remove the physical sticker. Take the sign down or cover it after you deactivate.
- It does not notify 911. Deactivating a code is an operations change, not an emergency.

## Who can deactivate

Same manage permission as creating codes: Campus Admin / Supervisor, Venue Admin / Supervisor / Operator, Transit Admin / Supervisor.

If **Deactivate** is missing, your role is view-only. Ask an admin or supervisor.

## Physical cleanup

After dashboard deactivate:

1. Remove or cover the posted QR.
2. Remove or reprogram the NFC tag if it will be reused at another location.
3. Walk a test scan to confirm the public report page no longer opens for that code.
