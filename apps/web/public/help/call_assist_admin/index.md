# Call Assist Admin Overview

Admin configures **bots, knowledge, users, records, and demo runners** for non-emergency Call Assist. CAD write-back stays fail-closed.

## Admin home

- Configuration / bots
- Live calls (read / intervene as policy allows)
- QA and records
- Users
- Demo runner for evaluation scenarios

Post-login destination is `/app/call-assist/admin` — never the PSAP jurisdiction dashboard.
