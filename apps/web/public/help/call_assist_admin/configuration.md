# Call Assist Configuration

1. Open **Configuration** (and bots when shown).
2. Set greeting language and AI disclosure required by Missouri / agency policy.
3. Ground the knowledge base in agency-approved articles only — the bot must not fabricate beyond KB.
4. Set confidence thresholds so uncertainty escalates to a human, not a guess.
5. Confirm the emergency transfer destination (Connect flow / live answer point).
6. Leave CAD create/update write-back **fail-closed** until written authorization and UAT.

Notify operators before you change greetings or transfer destinations mid-shift.
