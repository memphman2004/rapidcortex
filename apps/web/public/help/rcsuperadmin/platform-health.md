# Platform Health Dashboard

1. Open **Infrastructure / Platform health**.
2. Review Lambda errors, API p99 latency, DynamoDB throttles, and Cognito auth failures.
3. Triage ALARM-state CloudWatch items before customers feel them.
4. Coordinate maintenance windows and publish **Platform Notices**.
5. Keep customer PII out of alarm tickets — use agencyId and correlation IDs instead.

Health is cross-tenant. Act as a platform operator, not a PSAP dispatcher.
