# Onboarding an Agency

1. Open **Agencies** → create / provision.
2. Set agency type (`city`, `venue`, `campus`, `transit`, etc.) correctly — type drives product routing.
3. Invite the Agency Admin with the correct `custom:role`.
4. Confirm feature flags and CAD write-back remain fail-closed until contract + UAT.
5. Send the agency its sign-in URL and Help / Staff Guide links.

Wrong agency type or role collapses product verticals into PSAP routes — double-check before go-live.
