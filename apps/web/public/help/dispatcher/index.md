# Dispatcher overview

This Help tab is for **911 / PSAP** staff. Campus, venue, and transit employees use **Staff Guide** instead.

NexCort iQ enhances emergency communications. It does **not** replace CAD, telephony, dispatchers, or medical direction. AI text is a suggestion. Agency SOP and your supervisor win if they disagree.

## Your workspace

After you sign in at the agency URL IT gave you:

- **Incident queue** (left) — select the call you are working
- **Transcript** (center) — live or attached transcript, including original-language lines when multilingual is on
- **Intelligence** (right) — triage snapshot, protocol coach, dispatch actions
- **Connections** strip — API should show **live** before you work real calls

## Every shift

1. Sign in at the agency URL (not a bookmark to another tenant).
2. Complete MFA when prompted.
3. Confirm Connections is live.
4. Treat AI as decision support, not orders.

## More Help articles

Use the list in this panel for Silent Text, caller video, pinpoint, CAD entry, translation, and incident notes. Training access is unlimited.

If something breaks, note whether you see API offline, a 503, or an analyze error, then contact operations with the `requestId` if shown.
