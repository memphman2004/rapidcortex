# Caller card and premise notes

The **caller card** (when enabled) shows what NexCort iQ already knows about the caller or location: hazard flags, premise notes, and prior incident history.

## How to use it

1. Select the incident.
2. Open the caller card / premise panel.
3. Treat flags as **assistive**. Verify against the caller and CAD/premise file.
4. Do not assume a prior DV flag means the same persons are on this call.

If the card is empty, continue the call. Missing data is not a reason to delay dispatch SOP.
