# Adding Incident Updates

Use incident notes to capture dispatcher observations, status changes, and context that belongs with the record.

## How to add a note

1. Select the incident.
2. Open **Incident notes** / updates.
3. Write a clear, factual update (time-relevant, no speculation).
4. Save. The note is tied to your user identity and timestamp.

## Good notes

- What you heard / verified ("Caller confirms smoke coming from kitchen window")
- Actions taken ("Silent Text link sent", "Supervisor notified")
- Changes since last update

## Avoid

- Opinions about guilt or mental health labels outside SOP language
- Pasting full Silent Text threads when a summary plus audit link is enough
- Editing another dispatcher's note — add a new update instead

Notes are agency-scoped and appear in audit / export workflows used by supervisors, analysts, and auditors.
