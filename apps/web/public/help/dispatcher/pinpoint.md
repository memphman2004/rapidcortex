# Pinpoint location

**Rapid Cortex Pinpoint** asks the caller’s phone for a GPS location when the module is on.

## How to request

1. Select the incident.
2. Open **RAPID CORTEX PINPOINT**.
3. Send the location request to the caller’s mobile number.
4. When they approve, read the map point in the workspace.
5. Verify against what the caller says and CAD/ALI. GPS can be wrong indoors.

Pinpoint is assistive. It does not replace your location protocol.
