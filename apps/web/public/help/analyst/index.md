# Analyst Overview

Analysts work **analytics, QA trends, performance, SLA, and exports** — not the live dispatcher queue and not CAD entry.

## Your surfaces

- Analytics dashboard (volume, response, trends)
- QA trends and scorecards
- Dispatcher performance reports
- SLA reports
- CSV / compliance-oriented exports your role allows

## Rules

- Agency-scoped only — no cross-tenant data
- Exports may contain sensitive operational detail; use approved storage
- Do not reinterpret software scores as discipline without supervisor process
