# Analytics Dashboard

1. Open **Analytics**.
2. Set date range, queues, and comparison period.
3. Read call volume, response / talk-time, and outcome trends in staffing context.
4. Drill into spikes (weather, events, outages) before you brief executives.
5. Confirm anomalies with Supervisors — charts describe; they do not replace after-action reviews.

All views are agency-scoped. You will not see other tenants.
