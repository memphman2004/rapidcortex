# Pre-Alert Review

1. Open **Pre-alerts** for your unit.
2. Read inbound EMS notices (ETA, chief complaint summary as provided).
3. Acknowledge per hospital SOP so the sending agency knows you saw it.
4. Notify receiving clinicians and update **Capacity** if the alert will consume beds.
5. Escalate ambiguous or MCI-level alerts to Hospital Admin immediately.

Pre-alerts are hospital coordination messages — not 911 CAD incidents inside NexCort iQ.
