# User Account Support

1. Verify the requester's identity through the approved channel.
2. Locate the user under the correct agencyId.
3. Unlock, reset password, or re-enroll MFA per runbook.
4. Never ask the user to text a password or MFA code to you.
5. Log the support action for audit.

If the account is deactivated for cause, do not reactivate without Agency Admin approval.
