# Deactivating a User Account

1. Open **Users**.
2. Choose **Deactivate** (do not delete the record).
3. Access ends immediately on next token refresh / sign-in block.
4. Audit history and incident attribution remain for compliance.

Deactivate the same day someone leaves or changes jobs. Do not share logins across people. If a contractor returns later, reactivate or re-invite per HR policy — do not recycle passwords.
