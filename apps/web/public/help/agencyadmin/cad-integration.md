# CAD integration setup

CAD connection is configured with Agency IT and NexCort iQ onboarding.

1. Open **Integrations** or **CAD Connector / CAD Bridge** as licensed.
2. Read-only / shadow modes are the default for many pilots.
3. **Write-back stays off** until a signed addendum and an explicit go/no-go.

Never enable production write-back from a Help article. Use your CAD addendum and NexCort iQ operations.
