# SOP Library & Protocol Upload

The SOP library grounds Protocol AI and dispatcher coaching in **your** agency documents.

## Upload / update

1. Open **SOP Library**.
2. Upload the current approved package (PDF/DOC per your agency process).
3. Tag call types / protocols so the coach can match incidents.
4. Retire superseded versions — do not leave conflicting SOPs active.

Dispatchers should see protocol suggestions only from the active library. AI must not fabricate steps beyond grounded SOP content.
